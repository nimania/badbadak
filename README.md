# بادبادک

بادبادک یک پروژهٔ مستقل برای گردآوری و نمایش خبرهای چهره‌ها، سبک زندگی، سرگرمی و اتفاق‌های روز است. این مخزن، رابط فعلی بادبادک را از کد اصلی پندار جدا می‌کند و ابزار دریافت خوراک‌های مستقل را هم نگه می‌دارد.

## توسعه

پوشه را روی یک وب‌سرور محلی باز کنید؛ اجرای مستقیم فایل با `file://` اجازهٔ خواندن فایل‌های JSON را نمی‌دهد. برای نمونه:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## داده و به‌روزرسانی

- خوراک‌های برترین‌ها، رکنا و هفت‌صبح با اسکریپت‌های `scripts/collect_*.py` دریافت می‌شوند.
- داده‌های عمومی پندار و مشکی‌مدیا در `data/` نگهداری می‌شوند تا برنامه به مسیر فایل‌های پندار وابسته نباشد.
- زمان‌بندی GitHub Actions خوراک‌ها و داده‌ها را تازه می‌کند و GitHub Pages نسخهٔ استاتیک را منتشر می‌کند.
- هر خبر به منبع اصلی پیوند دارد. صفحهٔ جزئیات خبرهای پندار همچنان در پندار باز می‌شود.

## انتشار مستقل

مخزن به‌صورت GitHub Pages منتشر می‌شود. یک‌بار در **Settings → Pages → Build and deployment**، گزینهٔ **GitHub Actions** را به‌عنوان منبع انتشار انتخاب کنید. پس از آن، هر push به `main` نسخهٔ سایت را منتشر می‌کند و workflow زمان‌بندی‌شده داده‌ها را تازه می‌کند.

`pendar.io/badbadak/` فقط به نسخهٔ مستقل هدایت می‌شود؛ کد، ظاهر و خوراک‌های بادبادک در مخزن پندار نگهداری نمی‌شوند. لینک خبرهای پندار به صفحهٔ اصلی همان خبر در پندار می‌رود.

## حریم داده

این برنامه حساب کاربری یا دادهٔ شخصی جمع نمی‌کند. رأی نظرسنجی محلی و فقط در مرورگر کاربر ذخیره می‌شود.


## صفحات داخلی خبر

`python scripts/build_articles.py` متن خبرهای منابع خوراک را دریافت و لینک‌ها را بررسی می‌کند. خروجی شامل `data/article-index.json` و صفحات مستقل `news/<id>/index.html` است. فقط بدنهٔ مطلب و تصاویر مرتبط استخراج می‌شود؛ تبلیغات و خبرهای پیشنهادی کنار گذاشته می‌شوند. مجوز بازنشر منابع را ناشر بادبادک مدیریت می‌کند.

در انتشار و تازه‌سازی زمان‌بندی‌شده، دریافت و ساخت صفحات خودکار اجرا می‌شود. `--build-only` از متن‌های ذخیره‌شده صفحه می‌سازد. هنگام خطای دریافت، آخرین متن سالم با برچسب نسخهٔ ذخیره‌شده حفظ می‌شود؛ اگر متنی موجود نباشد، صفحه صریحاً دریافت‌نشدن متن کامل را نشان می‌دهد. خلاصه هرگز به‌عنوان متن کامل معرفی نمی‌شود.
