# جدول‌ساز فارسی — نسخهٔ آزمایشی مستقل

این پوشه روی شاخهٔ `feature/crossword-studio-foundation` ایجاد شده است؛ هیچ بخشی از سایت اصلی بادبادک تغییر نکرده است.

## راه‌اندازی
```bash
python3 crossword-studio/generate.py --size 15 --count 3
python3 crossword-studio/generate.py --input crossword-studio/sample.json --size 10 --count 2
```
خروجی‌ها در پوشهٔ `crossword-studio/output/` ساخته می‌شوند. موتور به شبکه، اینترنت، هوش مصنوعی یا API وابسته نیست.

## معماری داده
هر مدخل: `id`، `clue` (سؤال)، `answer` (پاسخ)، `category`، `difficulty`، `source`، `license` و `reviewed`.
جدول‌های ساخته‌شده از همان ساختار `CrosswordJsonV3` استفاده می‌کنند که بازی «جدول انار» تعریف کرده است: `grid`، `clues.horizontal`، `clues.vertical` و `meta`.

## منابع
- بازی فعلی بادبادک فقط iframe از https://blankuapp.github.io/PersianCrossword/ است.
- کد پروژه BlankuApp/PersianCrossword تحت MIT است؛ این امر به خودی خود مجوز بازنشر محتوای روزنامه‌های منبع را تأمین نمی‌کند.
- مجموعهٔ https://huggingface.co/datasets/PerSets/crossword-puzzle-persian-cheat با برچسب CC0 برای بررسی و ورود پس از کنترل کیفیت پیشنهاد شده است. اعتبار مجوز و خاستگاه داده پیش از انتشار انبوه بازبینی شود.
- نمونهٔ حاضر با مدخل‌های اولیهٔ آزمایشی کار می‌کند و ادعا نمی‌کند دادهٔ بازی موجود را کپی کرده است.

## مراحل بعد
۱. افزودن واردکنندهٔ TSV/CSV و پالایش نیم‌فاصله، ی/ي، ک/ك و تکرار.
۲. بانک SQLite با تاریخچهٔ استفاده و بازبینی انسانی.
۳. موتور backtracking برای پوشش بیشتر و جدول‌های متراکم.
۴. ویرایشگر راست‌به‌چپ و پیش‌نمایش، چاپ، انتشار در بادبادک.

**محدودیت نسخهٔ نخست:** موتور فعلی جدول‌های پراکنده با تقاطع معتبر می‌سازد، نه جدول روزنامه‌ای کاملاً پر. خروجی صرفاً طرح اولیه است و باید پیش از انتشار بازبینی شود.
